# 🔵 Lógica de Programação e Algoritmos com C

Repositório dedicado aos meus estudos no curso **Lógica de Programação e Algoritmos com C** da [Udemy](https://www.udemy.com), ministrado pelo professor **Gustavo Caetano**. Contém os exemplos, exercícios e projetos práticos desenvolvidos ao longo do curso.

| Ponteiros | Sintaxe, ponteiro em função, inversão de vetores |

## ▶️ Como Executar

1. Clone o repositório:

```bash
git clone https://github.com/gustavopurkoot/Logica-de-Programacao-e-Algoritmos-com-C.git
```

2. Navegue até a pasta do arquivo desejado e compile:

```bash
cd caminho/do/arquivo
gcc arquivo.c -o saida
./saida
```

> Para arquivos que usam `math.h`, adicione `-lm` ao compilar:
> ```bash
> gcc arquivo.c -o saida -lm
> ```
